-----------------------------------------------------------------
BACKEND FUNCTIONALITY
-----------------------------------------------------------------
1. Authentication
   - `/api/auth/login` REST endpoint implemented in `AuthController`. (Completed)
   - `/api/auth/register` REST endpoint implemented in `AuthController`. (Completed backend)
   - Security config permits `/api/auth/login` publicly. (Completed)
   - Security config requires ADMIN role for `/api/auth/register`. (Completed)
   - All other API requests require JWT authentication. (Completed)

2. Reports (`RapportController`)
   - `GET /api/rapports` returns all reports. (Completed)
   - `GET /api/rapports/{id}` returns a report by id. (Completed)
   - `GET /api/rapports/etudiant/{auteurId}` returns reports by student. (Completed)
   - `GET /api/rapports/encadrant/{encadrantId}` returns reports by supervisor. (Completed)
   - `POST /api/rapports` creates a report from request body. (Completed)
   - `PUT /api/rapports/{id}/valider` validates or updates report status. (Completed)
   - `DELETE /api/rapports/{id}` deletes a report. (Completed)

3. User management (`UserController`)
   - `GET /api/users` returns all users. (Completed)
   - `GET /api/users/{id}` returns a user by id. (Completed)
   - `DELETE /api/users/{id}` deletes a user. (Completed)

4. Supervision requests (`DemandeEncadrementController`)
   - `POST /api/demandes` submits a supervision request. (Completed)
   - `PUT /api/demandes/{id}/repondre` accepts/rejects a request. (Completed)
   - `GET /api/demandes/encadrant/{encadrantId}` fetches supervisor requests. (Completed)
   - `GET /api/demandes/etudiant/{etudiantId}` fetches student requests. (Completed)
   - `GET /api/demandes/encadrant/{encadrantId}/en-attente` fetches pending supervisor requests. (Completed)

5. Notifications (`NotificationController`)
   - `GET /api/notifications/user/{userId}` returns notifications for a user. (Completed)
   - `GET /api/notifications/user/{userId}/unread` returns unread notifications. (Completed)
   - `POST /api/notifications` creates a new notification. (Completed)
   - `PUT /api/notifications/{id}/lire` marks a notification as read. (Completed)

6. Deadlines (`DeadlineController`)
   - `GET /api/deadlines` returns deadlines. (Completed)
   - `POST /api/deadlines` creates a deadline. (Completed)
   - `DELETE /api/deadlines/{id}` deletes a deadline. (Completed)
